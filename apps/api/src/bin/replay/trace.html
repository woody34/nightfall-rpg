Decoded tick window · @@WINDOW@@

The fixed window is ±20 ticks around the failure (or the first recorded tick), clipped to the recording. All observers remain visible; selected-session outputs are highlighted. Private resources appear only in the selected owner’s output; admission loads, checkpoint state and transfer receipts are hidden. Class transfers are actor commands from gRPC, not WebSocket intents. Digest-only output bytes cannot be decoded; any digest-only map facts are reconstructed by the current replay engine, not verified recorded bytes.
