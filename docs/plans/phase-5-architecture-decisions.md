## 1. Architect decisions (binding)
- A1 Invariants unchanged (server authoritative, 100 ms tick, per-zone ChaCha12, Q=1_000_000 i64 fixed point with i128 checks, no floats/HashMap/wall clock in domain/zone, additive wire, byte-exact legacy replay, critical-mutation order draft → log ack → fenced checkpoint + outbox → visible output). All 05 float/HashMap/tokio-interval/DB-first/UUIDv7/per-request-RNG designs are rejected (brief B1–B7).
- A2 Authority: ALL economy state that affects simulation is zone-canonical: ground items (entity kind GroundItem with owner/party protection timers, decay ticks), corpses (spoiled flag, sweep window), vendor sessions (buy/sell/refund tab), multisell/craft resolutions, trade sessions (two-phase), private stores, mail is DB-only (out-of-world mailbox) but attachments move through the zone critical path of the sender/receiver when admitted (peace-zone rule pinned). Warehouse/freight are DB-only containers with zone-mediated deposit/withdraw critical mutations (the inventory side is zone state). Item auction and manor: DB-only schedules + zone-mediated item movement.
- A3 Wire (additive): new message types in packages/proto/nightfall/v1/economy.proto; intents from the first free ClientMessage tag after Phase 4 (re-verify; expected 29+), WorldEvent 34+, RejectReason 38+, StatsChanged/EntitySpawn next free; GameService RPCs appended (ListBuylist, Buy/Sell happen as zone intents; GetWarehouse/Deposit/Withdraw as RPC+zone; mail RPCs; GetRecipeBook; auction/manor RPCs). Enum-name prefixes. New entity kind GroundItem on EntitySpawn (additive fields). No new envelopes/streams.
- A4 Version boundary: Snapshot 11 / Record 9 / Binary V7 for epochs with Phase 5 semantics (ground items, corpses, drop RNG draws, vendor/craft/trade resolutions change state and RNG draw order); V6 and older byte-exact. Phase5Rules = separately hashed bundle (drop tables, spoil tables, herb tables, buylists, multisell, recipes, rate multiplier, ownership/decay constants, tax constants, party loot constants, storage limits, mail limits, auction/manor data), hash-referenced like Phase4Rules (D27), never embedded. PHASE5_ENABLED gate like PHASE3/PHASE4.
- A5 RNG: all drop/spoil/craft/auction draws come from the per-zone stream in fixed in-tick order (death resolution phase after kill credit; craft at resolution; spoil at skill impact) with integer adaptations proven by oracle (pinned precise-drop algorithm with chance > 100% semantics: `PreciseDropMultipleGroupRolls=False`, `…AggregateDrops=False` pinned; level-gap windows: items 5/10 → 10 % steps, adena ungrouped 8/15 — all pinned adena entries are grouped so the item window applies; champion multipliers ×8 pinned; rate multiplier applied as exact rational before the integer draw).
- A6 Drops: death lists (`<group chance>` + ungrouped items) and corpse lists (ungrouped, each rolled independently) generated from the pinned NPC XML (124 files; 59 with death lists, 52 with corpse lists); killer = top-damage online player at death; ground item creation via the item critical path (allocated ItemInstanceId, ledger op `drop`), protection 15 s to killer + party (pinned), raid rule per defaults; decay 600 s items / 60 s herbs (pinned), per-template auto_destroy_time overrides; player-dropped items not auto-destroyed (pinned SaveDroppedItem=False semantics as the brief states; document). Herbs: `ex_immediate_effect` items apply on pickup without inventory slot (68 items). Pickup = intent (PickUp) resolved in the command phase with range/ownership/capacity (can_accept) checks; party loot modes (5 pinned) and adena even split within PartyRange2 1400 units; ledger op `pickup`.
- A7 Spoil/Sweep: Spoil (254) success via calcMagicSuccess (pinned), sets corpse spoiled flag; Sweeper (42) hitTime 500 / reuse 500 / MP 3 (pinned) by the spoiler or any member of the spoiler's party; items go to the sweeper via the item path (op `sweep`); corpse decay 7 s default + spoil extension (pinned per-NPC corpseTime overrides).
- A8 Vendors: buylists (195) with pinned restock (`count`/`restock_delay`), buy price = price × (1 + baseTax + castleTax) with castleTax at the no-owner rate until castles (integer per-mille arithmetic, rounding per pinned RequestBuyItem), sell = price/2 with refund tab (max 12, pinned), `is_sellable` gate, package sale; Giran luxury shop as data. Vendor interaction = NPC proximity (radius 3) like the Class Master/Blacksmith; buy/sell are zone intents with receipts (ops `vendor_buy`/`vendor_sell`); adena is a stackable item (template 57) — all adena movement is ledgered.
- A9 Multisell (196 lists): generic exchange engine reusing D37/D52 ExchangeAudit (consume ingredients + grant product; maintainEnchantment copies enchant AND augment AND elemental attributes, pinned MultiSellChoose.java:355-362); taxes per list flag; one ItemExchanged per exchange.
- A10 Crafting: recipe book (register consumes the recipe item; limits 50/50), Create Item ranks gate recipe level, MP cost paid at resolution (pinned order), success roll from the per-zone stream, masterwork roll (pinned), 100% material loss on failure, product via item path (op `craft`); manufacture for others (private workshop) is part of private stores scope.
- A11 Trade: two-phase atomic trade (pinned TradeList semantics; both confirm; validation at commit; 150-unit distance / 120 s timeout are Nightfall rules and must be documented as such or replaced by pinned flood-protector semantics — design decides and cites), executed as ONE critical mutation moving instances between two zone-canonical inventories (ops `trade_out`/`trade_in` linked by one receipt), with capacity checks on both sides; private stores (buy/sell/package/manufacture) as persistent zone state with pinned slot limits 3/4 (Dwarf 4/5), OfflineTradeEnable=False (pinned).
