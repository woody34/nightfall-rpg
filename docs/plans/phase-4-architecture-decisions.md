## 6. Zone decisions and deviations recorded in-tree (sessions 8–10)

- **Phase 4 deviation PD1 — unarmed after a 3rd-class transfer (D84 re-resolution).** Pinned `L2PcInstance.findFistsWeaponItem` (L2PcInstance.java:2141-2183) maps class ids 0x00–0x39 to fists templates 244–252 and returns null for 3rd-class ids (≥ 88); `_fistsWeaponItem` is only set at login (PlayerDAOMySQLImpl.java:105), so retail keeps the login fists after a 3rd-class transfer until relog. The engine re-resolves the fists template from the current class on every rebuild/attack (D84). Consequence, only in the window between a 3rd-class transfer (level 76+) and relog, for an unarmed player:
  - **reach** falls back to the class_combat unarmed attack range (pinned baseAtkRange 20, Orc lines 25 → 625 / 781 milli-tiles) instead of the fists' 40 (1250 milli-tiles);
  - **random damage** falls back to `5 + isqrt(level)` (D24; e.g. 13 at level 76) instead of the fists' 5 (10 for the Orc Shaman fist 252);
  - **attack angle** falls back to the unarmed_combat angle 120 instead of the fists' angle.
  Bound: unarmed attacks of 3rd-class characters only; equipped weapons and all other classes are unaffected. Not changed in Phase 4.
