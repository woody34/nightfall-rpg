# Engine research: Unreal Engine 5

- **Engine version that we evaluated:** Unreal Engine 5.8 (released 2026-06-17; the last planned 5.x release). 5.7 was released on 2025-11-12, and 5.6 on 2025-06-03. The target for UE6 early access is late 2027.
- **Research date:** 2026-10-07
- **Project context:** Nightfall, an MMORPG that Lineage 2 inspired. The Rust server is authoritative (axum + tonic + NATS). The client uses gRPC-web for request/response, and a WebSocket with protobuf frames for real-time data. Native desktop is necessary; a browser client is desirable. The team has one person.
- **Status key:** Native = in the engine, Plugin = Epic or third-party plugin, Partial = available with gaps, Missing = no usable path. **Maturity** uses the labels of Epic (Experimental / Beta / Production-Ready) where Epic publishes one. In other conditions, it uses stable / beta / experimental / abandoned from the activity.

## Narrative

### Strengths

Unreal Engine 5.8 is the most complete toolkit for a 3D MMO client. You do not pay money to use it. At the rendering layer, the items that an MMORPG needs are not plugins or roadmap items. They are the reason that the engine exists:

- World Partition with One File Per Actor and HLOD for a seamless continent.
- Nanite for geometry density.
- Lumen and MegaLights (now Production-Ready) for fully dynamic lighting. With these, a 4-hour day cycle is a one-line light rotation, not a baking problem.
- Virtual Shadow Maps and Niagara.
- A character pipeline that no other engine has: Control Rig, IK Rig, retargeting, and Production-Ready Motion Matching with 500+ free mocap clips.

Each large Korean MMO of the last ten years selected Unreal for exactly this reason. Examples are Lost Ark on UE3, Throne and Liberty on UE4, and Aion 2 on UE5. Ashes of Creation put 8,100 players on one UE5 realm.

The commercial terms are also good for a solo developer:

- There is no royalty until $1M lifetime gross for each product.
- After that, the royalty is 3.5% if you release on the Epic Games Store on day one.
- There is no EGS fee on the first $1M each year.
- The full engine source is free on GitHub.

With Fab and Megascans, you can solve most of the asset problem with a credit card. For a one-person MMO, the asset problem is frequently the second largest problem.

### Weaknesses

The strengths are all in the parts of the engine where Nightfall does not need help. The weaknesses are in the parts where Nightfall needs help.

**Networking.** The multiplayer stack of Unreal (Actor replication, Iris, GAS prediction, Network Prediction, Mover rollback, CMC client correction) is one vertically integrated design. In this design, a UE dedicated server is the only authority. The authority of Nightfall is a Rust process that uses protobuf over WebSocket and gRPC. Thus, the client would run as a standalone game and use none of that machinery. We would write the snapshot buffers, the interpolation and the ability records again by hand in C++. Korean MMO studios do exactly this with their custom C++ servers, thus it is proven. But it means that a solo developer gets a 43 GB engine and then does not use its most sophisticated gameplay functions. The primitives that stay useful also have problems:

- The WebSocket module is C++ only.
- gRPC needs TurboLink or a gRPC-cpp that you build by hand. You must compile it against the exact toolchain of UE, and it must not conflict with the abseil copy that the engine already includes.
- There is no gRPC-web client. On desktop this is not important, but it prevents all paths to a shared browser protocol.

**Rust reuse.** The domain crate of the project cannot run in UE as Rust. `unreal-rust` is an explicitly unfinished proof of concept, with its last push in mid-2024. `uer` is an experiment with six commits. The only durable path is a C ABI (`cbindgen`) that you maintain by hand, with UObject wrappers that you write by hand. This is a second integration layer that you must keep for all time. In practice, the shared artifact will be the `.proto` files, not the Rust code.

**Iteration speed.** This is the real cost for a team of one:

- The baseline of Epic for local compiles is 12-16 cores and 32 GB RAM.
- C++ builds at the project level take from ten seconds to ten minutes.
- Live Coding cannot do header or reflection changes, and 5.8 was released with a recompile-loop regression.
- Shader compiles stop the editor after many material changes.
- GPU "device removed" crashes are a frequent forum subject through 5.7.

Blueprints are instant. But the usual code of an MMO client must be in C++, not in Blueprint graphs. Examples are protocol decoding, state buffers and inventory logic.

**Web and footprint.** There is no UE5 browser export. HTML5 was removed from mainline in 4.24. The community forks stop at UE 4.27, package only on Windows, and are in maintenance mode. The Wonder Interactive / SimplyStream WebGPU port showed demos since 2024, but it has no public release. Pixel Streaming needs a GPU server for each small group of users. A blank Win64 shipping build is approximately 321 MB. If the browser prototype needs a successor, Unreal cannot be that successor.

**Platform churn.** UE releases two majors each year with no LTS, and Experimental systems (Mover, Mass, Nanite skinning) change between them. More importantly, on 2026-06-17 Epic said that UE6 (early access late 2027) replaces the Actor framework with a Scene Graph that uses Verse. UE6 also merges UEFN in, and Blueprints start a long sunset. A client built on Actors and Blueprints in 2026 will still operate in UE5. But it will not be the way that Unreal operates when Nightfall is mature.

### Fit for Nightfall

Unreal is the correct decision if these three conditions are true:

- The primary competitive axis of Nightfall is visual fidelity on a 3D continent.
- We formally remove the browser target.
- The developer already writes UE C++ fluently and has a 16-core workstation.

In those conditions, the rendering, world-streaming and animation problems go away. The remaining work is a thin network client that is well understood. Aion 2 and Ashes prove that this is possible.

The actual project has one developer, an authoritative Rust server, protobuf over WebSocket, a desirable browser deployment, and a Phaser prototype now. For this project, the fit is poor to moderate. The special value of the engine is in subsystems that Nightfall will not use or must go around (replication, GAS, Mover, Verse). Its special costs are compile times, the hardware floor, and no web target. Other costs are Rust reuse only through FFI, and changes each six months toward a UE6 rewrite. These costs are all on the one person who does the work. The honest summary: Unreal would make Nightfall look like an AAA MMO long before it makes it play like one. A solo developer does not have the time between those two points.
