# Engine research: Unreal Engine 5

- **Engine version evaluated:** Unreal Engine 5.8 (released 2026-06-17; final planned 5.x release). 5.7 shipped 2025-11-12, 5.6 on 2025-06-03. UE6 early access is targeted for late 2027.
- **Research date:** 2026-10-07
- **Project context:** Nightfall, a Lineage 2-inspired MMORPG. Authoritative Rust server (axum + tonic + NATS). Client talks gRPC-web for request/response and a WebSocket carrying protobuf frames for real-time. Native desktop required; browser desirable. Team of one.
- **Status key:** Native = in-engine, Plugin = Epic or third-party plugin, Partial = exists but with gaps, Missing = no viable path. **Maturity** uses Epic's own labels (Experimental / Beta / Production-Ready) where Epic publishes one; otherwise stable / beta / experimental / abandoned based on activity.

## Narrative

### Strengths

Unreal Engine 5.8 is the most complete 3D MMO client toolkit money cannot buy. The things an MMORPG needs at the rendering layer are not plugins or roadmap items, they are the engine's reason to exist: World Partition with One File Per Actor and HLOD for a seamless continent, Nanite for geometry density, Lumen and the newly Production-Ready MegaLights for fully dynamic lighting (which makes a 4-hour day cycle a one-line light rotation rather than a baking problem), Virtual Shadow Maps, Niagara, and a character pipeline (Control Rig, IK Rig, retargeting, Production-Ready Motion Matching with 500+ free mocap clips) that nothing else matches. Every large Korean MMO of the last decade, from Lost Ark on UE3 through Throne and Liberty on UE4 to Aion 2 on UE5, chose Unreal for exactly this. Ashes of Creation has put 8,100 players on one UE5 realm.

The commercial terms are also friendly to a solo developer: no royalty until $1M lifetime gross per product, 3.5% after that if you ship on the Epic Games Store day-one, zero EGS fee on the first $1M per year, and full engine source on GitHub for free. Fab plus Megascans means the asset problem, usually the second-biggest problem for a one-person MMO, is mostly solved with a credit card.

### Weaknesses

The strengths are all on the side of the engine Nightfall does not need help with, and the weaknesses are concentrated on the side it does.

**Networking.** Unreal's multiplayer stack (Actor replication, Iris, GAS prediction, Network Prediction, Mover rollback, CMC client correction) is a vertically integrated design around a UE dedicated server as the single authority. Nightfall's authority is a Rust process speaking protobuf over WebSocket and gRPC. The client would therefore run as a standalone game and use none of that machinery, re-implementing snapshot buffering, interpolation and ability bookkeeping by hand in C++. This is exactly what Korean MMO studios do with their custom C++ servers, so it is proven, but it means a solo developer buys a 43 GB engine and then declines its most sophisticated gameplay-layer features. Even the primitives that remain useful carry friction: the WebSocket module is C++-only, gRPC requires TurboLink or a hand-built gRPC-cpp that must be compiled against UE's exact toolchain and must avoid colliding with the abseil copy the engine already ships, and there is no gRPC-web client at all (irrelevant on desktop, but it closes the door on any shared browser protocol path).

**Rust reuse.** The project's domain crate cannot run inside UE as Rust. `unreal-rust` is an explicitly unfinished proof of concept with its last push in mid-2024; `uer` is a six-commit experiment. The only durable path is a hand-maintained C ABI (`cbindgen`) with UObject wrappers written by hand, which is a second integration layer to carry forever. In practice the shared artifact will be the `.proto` files, not the Rust code.

**Iteration speed.** This is the real cost for a team of one. Epic's own baseline for local compiles is 12-16 cores and 32 GB RAM; project-level C++ builds swing from ten seconds to ten minutes; Live Coding cannot handle header or reflection changes and 5.8 shipped with a recompile-loop regression; shader compiles stall the editor after many material changes; GPU "device removed" crashes are a recurring forum theme through 5.7. Blueprints are instant but the usual MMO-client code (protocol decoding, state buffers, inventory logic) is precisely the kind of code that belongs in C++, not in Blueprint graphs.

**Web and footprint.** There is no UE5 browser export. HTML5 left mainline in 4.24; the community forks stop at UE 4.27, package only on Windows and are in maintenance mode; the Wonder Interactive / SimplyStream WebGPU port has shown demos since 2024 but has no public release; Pixel Streaming is a GPU server per handful of users. A blank Win64 shipping build is roughly 321 MB. If the browser prototype ever needs a successor, Unreal cannot be it.

**Platform churn.** UE ships two majors a year with no LTS, and Experimental systems (Mover, Mass, Nanite skinning) change between them. More importantly, Epic stated on 2026-06-17 that UE6 (early access late 2027) replaces the Actor framework with a Verse-based Scene Graph and merges UEFN in, with Blueprints starting a long sunset. A client built on Actors and Blueprints in 2026 will still work in UE5, but it will not be the way Unreal works by the time Nightfall is mature.

### Fit for Nightfall

Unreal is the right choice if Nightfall's primary competitive axis is visual fidelity on a 3D continent, if the browser target is formally dropped, and if the developer already writes UE C++ fluently and owns a 16-core workstation. Under those conditions the rendering, world-streaming and animation problems disappear and the remaining work is a thin, well-understood network client, with Aion 2 and Ashes as existence proofs.

For the project as actually described (one developer, Rust-authoritative server, protobuf over WebSocket, browser deployment desirable, Phaser prototype today) the fit is poor-to-moderate. The engine's unique value sits in subsystems Nightfall will not use or will have to route around (replication, GAS, Mover, Verse), while its unique costs (compile times, hardware floor, no web target, FFI-only Rust reuse, six-month churn toward a UE6 rewrite) land squarely on the one person doing the work. The honest summary is that Unreal would make Nightfall look like a AAA MMO long before it makes it play like one, and the time between those two points is the time a solo developer does not have.
