NPC state machine

Tick order: commands → spawn phase (expired corpses despawn, then due members respawn in slot/member order) → AI phase (NPCs in id order) → chase → movement → impacts → hit bookkeeping → next swings → AOI output. Attack and ReturnHome are checked every tick; everything else runs on the think tick, tick % 10 == EntityId % 10.

Entering Attack comes from the reselect hook whenever an idle or active NPC acquires a target: its own aggro scan, a player's hit, or a clan call. The first engagement calls idle/active NPCs of the same clan within clan_help_range (id order, 1 hate each); helpers never call. Leash is the NPC's distance from home; the timeout counts from entering Attack or the last landed hit.

RNG: a first life draws its id; an Active mobile NPC without prey draws roll_below(30) per think and, on 0, dx then dy; death draws the respawn jitter 0..=random unless it is 0. Respawn at max(death + 10·(delay + jitter), corpse_until + 1). Intention changes are internal events: in AppliedTick and the record, never on the wire.
