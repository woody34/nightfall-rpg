Record, export, replay, compare

nightfall-replay --zone 1 --epoch N (or --latest) reads JetStream; export … --out FILE writes a .nfr (magic NFREPLAY, format version, zlib protobuf of snapshot + records + watermark); --source file --file FILE replays one. --session ENTITY selects whose outputs are compared; every command is still applied. A gap or truncated log exits 2.

The first mismatch stops the run: server_time_ms, dispositions, which players got output, then each player's output (digest-only records compare digests). The checked-in fixture is apps/api/fixtures/sessions/two-players-v4.nfr, replayed by moon run api:replay-check in CI.
