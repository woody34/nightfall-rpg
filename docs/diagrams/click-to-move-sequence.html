Nightfall · Sequence · Minimal light

Click to move

01–03: OnClickMove raycasts the ground (falling back to the Z=ground plane when nothing is hit) and calls MoveToWorldLocation: SimpleMoveToLocation starts the local preview at once, and the destination goes out as tiles (cm / 100, UnitsPerTile) in MoveTo with a new seq. Logged at Verbose (LogNightfall).

04–06: Exactly one Ack{seq, tick} or IntentRejected{seq, reason} comes back (OUT_OF_BOUNDS, TOO_FAR beyond 64 tiles, RATE_LIMITED, ...). A rejection for the pending seq stops the preview, puts the pawn back on the last server position and shows the reason in the status line.

07–08: EntityMove for the own entity (the character id) reaches UOwnEntityComponent, never a proxy. The pawn snaps to the server position when more than 3 tiles away (this is also how it lands on its EntitySpawn tile), re-issues the local move if the server destination differs from the clicked one by more than 1 tile, and walks at the server speed (tiles/s), nudged to stay level with the server. Speed 0 means stopped.

Source: NightfallPlayerController.cpp · OwnEntityComponent.cpp · NetClientSubsystem.cpp · world.proto.
