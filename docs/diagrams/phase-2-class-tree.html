Authoritative data source and revision: Profession attributes and hierarchy derive from packages/data/professions/*.toml, anchored to upstream Lineage 2 High Five datapack revision 3ca488dd2bd0bfaca43e378886a3c2e37968153a (l2j-server-datapack). Each node displays its stable ID and curated original Nightfall name on the first line, with the upstream reference name (l2_ref) on the second. The upstream pin supports mechanics and lineage, not the project-authored display names. Tier headers show minimum levels.

Corrected hierarchy metadata: The graph reflects authoritative structural fixes over historical upstream errata: Edge Cantor (ID 34) correctly connects to parent Gloamguard (ID 32), and Tide Sovereign (ID 104) connects to parent Tidekeeper (ID 28).

Phase 2 bounds and availability: All 89 nodes are uniquely indexed. Playable characters start at level 1 in Tier 0 (Creation). Class transfers are eligible at level 20 for Tier 1 and level 40 for Tier 2. Phase 2 enforces a playable level cap of 85 and a maximum transfer tier of 2. Tier 3 professions (level 76 minimum) are catalogued but deferred/locked from live admission.
