Stat derivation: source to combat

Build time. gen_tables.py refuses any revision but the pinned l2j-server-game and l2j-server-datapack commits, parses every constant from a literal source line, and writes each decimal as its literal string plus its exact integer at Q = 1,000,000. --check fails on drift.

Startup. rules_data parses decimals without floating point and checks literals, coverage, references and provenance; StatRules::new checks invariants and derives every class at every level. Any failure aborts startup listing every error. ResolvedRules (rules plus canonical config_hash) is injected with ZoneBootstrap::with_rules.

Runtime. StatSheet holds unrounded Q values; the combat and progression functions take the caller's random draws, so they never touch the zone RNG. NPC templates enter as final values through StatSheet::from_final (not shown).
