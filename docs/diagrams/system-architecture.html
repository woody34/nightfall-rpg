System architecture

Development ports shown. The four server boxes group modules, not separate services. Zone commands use in-process mpsc; NATS carries the transactional outbox, replay log and best-effort session audit. The outbox relay waits for the publish ack before marking a row published.

NF_EVENTS → nightfall.*.* (currently nightfall.character.created); NF_ZONES → nightfall.zone.*.*.*; NF_SESSIONS → nightfall.session.*.*. These subject sets do not overlap.

LGTM groups Grafana, Loki, Tempo and the metrics backend; the local grafana/otel-lgtm image uses Prometheus. Keycloak also stores its own database in the local Postgres service (edge omitted).
