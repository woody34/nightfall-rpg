Persistence data model

Entity-level view of the final migrations, cross-checked against SeaORM models. Comma-separated names are separate columns. Only two foreign keys are declared: account_sessions.account_id → accounts.id and play_tickets.character_id → characters.id; both use ON DELETE CASCADE. Account links from characters, idempotency_keys and play_tickets are application-level associations. The last is field-only to avoid a crossing.

idempotency_keys has PK (account_id, operation, key); the old character_id column was dropped. zone_snapshots has PK (zone_id, epoch). outbox and zone_snapshots have no foreign keys. characters.revision is the checkpoint fence (each applied checkpoint bumps it); hp/mp NULL means full on load. SQL types, checks, defaults and indexes remain in the migrations.
