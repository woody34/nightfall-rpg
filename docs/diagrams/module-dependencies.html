Clean architecture: actual dependencies

Composition: main.rs, lib.rs, config.rs, zone_runtime.rs. Direct imports into inner layers are folded into composition wiring. Tests and third-party crates are omitted.

Interface: grpc, http, ws, zone_mapping. Application: use_cases, ports, error, replay_log, session, trace, zone_actor, zone_bootstrap, zone_registry. Domain: account, character, events, ids, session, zone.

Infrastructure: auth, eventlog, memory, nats, outbox, postgres, secrets, telemetry, zone_data. Adapters implement application ports; domain has no runtime, transport or database imports. Application orchestration uses Tokio and tracing.

The intended dependency direction is inward. The graph also shows the current exception: interface::http and interface::grpc::auth import infrastructure::telemetry. There is no module-level production cycle in this view.
